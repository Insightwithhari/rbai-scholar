# Changes

What changed in RBAi Scholar and in this repository, newest first. All dates are in 2026.

## 21 November

- First public release of this repository: the user guide, the REST API and MCP guides, client configurations,
  examples, and the benchmark (data, results, figures and the scorer).
- MCP Registry entry 1.0.4: links this repository, and the API key header is now optional, because ChatGPT and
  Claude can sign in with an email code instead. Entry 1.0.5 says the same in the header's description.
- Sign-in: sending a form twice (a double click on Continue or Allow) no longer ends the sign-in.
- The licence is now in two files: [LICENSE](LICENSE) (MIT, for the code) and [LICENSE-DATA.md](LICENSE-DATA.md)
  (CC BY 4.0, for the data and documentation).
- Added [SECURITY.md](SECURITY.md), [CONTRIBUTING.md](CONTRIBUTING.md) and this file.

## 18 November

- A paper's references and the papers citing it are ranked by how similar they are to that paper, and each
  result shows its similarity.
- Years are labelled "first published".
- A note says when the closest papers are only loosely related to the question.

## 16 November

- MCP Registry entry 1.0.3: over 24 million biomedical journal abstracts, more than 20 million of them in PubMed.

## 15 and 16 November

- Four tools added: look up papers by PMID or DOI, find similar papers, get a paper's references, and get the
  papers citing it. Results can be exported as RIS or BibTeX.

## 12 November

- Sign in with RBAi Scholar: ChatGPT and Claude connect with an email code, with no key needed.
- A daily allowance per key: 20 searches on the free plan and 500 on Pro.

## 4 October

- First MCP Registry entry (1.0.0).
